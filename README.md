# Marwan Hatem: AI Engineer Portfolio

Personal portfolio built with [Astro](https://astro.build) and Tailwind CSS, deployed to GitHub Pages.

Live site: https://marwan55hatem.github.io/My-portofolio/

## Run locally

```bash
npm install
npm run dev
```

## Edit content

- Projects: `src/content/projects/*.md`
- Home page sections: `src/pages/index.astro`
- CV PDF: `public/Marwan_Hatem_CV.pdf`

Every push to `main` rebuilds and deploys the site through `.github/workflows/deploy.yml`.
